📋專案概述

本教材為 115-116 年度教育部補助師資培育計畫成果，以「光的折射」為主題，提供國小學生探究式學習的互動數位教材，部署於 GitHub Pages 供師生隨時存取。

分頁切換機制

教材採用「單頁應用」（SPA）模式，所有分頁面板同時存在於 DOM，以 CSS display:none / display:block 控制顯示，避免頁面重新載入。

function go(id) {
  document.querySelectorAll('.panel').forEach(p => p.classList.remove('active'));
  document.querySelectorAll('.tab').forEach(t => t.classList.remove('active'));
  document.getElementById(`tab-${id}`).classList.add('active');
  document.querySelector(`.tab[data-tab="${id}"]`).classList.add('active');
  if(id === 'exp1') setTimeout(resizeChopCv, 80);
}

⚙️核心互動功能
4.1 實驗一：光線折射模擬
💡
容器外入射段
光線從容器頂端上方射入，以黃色細線 + glow 光暈繪製，並加上箭頭指示傳播方向，解決舊版竹籤圖示超出容器邊框的問題。
🌊
多層介質支援（空氣 / 水 / 食用油）
最多三層介質（空氣固定 + 水 n=1.33 + 食用油 n=1.47），每個界面獨立計算折射角，並以波紋動畫線標示界面。
🔭
比較模式（空氣 vs 目前配置）
開啟後在同一 Canvas 並排顯示「只有空氣」與「目前介質配置」，讓學生直觀比較折射差異。
📐
法線、入射角、折射角標示
每個折射點自動繪製紅色虛線法線，以弧形標示入射角（黃色）與折射角（橙色），並顯示角度數值，強化物理概念連結。
// 繪製入射光（容器外）
const inLen = 54;
const ix0 = cx2 - Math.tan(rad) * inLen, iy0 = cy2 - inLen;
ctx.save();
ctx.shadowColor = 'rgba(255,235,60,0.9)';
ctx.shadowBlur = 10;
ctx.strokeStyle = 'rgba(255,235,60,1)';
ctx.lineWidth = 2;
ctx.beginPath(); ctx.moveTo(ix0, iy0); ctx.lineTo(cx2, cy2); ctx.stroke();
ctx.restore();
4.2 實驗二：硬幣虛像模擬
🪙
大/小容器並排，加水動畫
兩個不同尺寸容器同步顯示，滑桿控制水位（0–100%），支援「自動加水」動畫效果，讓學生觀察水位對虛像偏移的影響。
🎯
點擊定位互動（找真正的硬幣）
學生可點擊 Canvas，程式計算點擊位置與真實硬幣的距離，給出「正確！」或「再找找看」的即時回饋，強化探究精神。
🔦
光線路徑顯示（可選）
勾選「光線路徑」可顯示兩條光路：穿過水面折射的虛像光線（橙色），及未折射的實際光線（藍色），協助理解雙像成因。
4.3 折射原理動畫
▶️
入射角 0→80° 動態播放
點擊「播放動畫」，入射角從 5° 逐漸增大至 80°，折射角同步更新，以動態方式呈現斯乃爾定律的角度關係，並即時顯示角度數值。
4.4 生活應用場景圖

🔬斯乃爾定律實作

光在介質界面折射遵循斯乃爾定律，程式以 JavaScript 精確實作：

n₁ · sin(θ₁) = n₂ · sin(θ₂)
// 每個界面的折射計算（Snell's Law）
const sn = Math.sin(curAng) * curN / layers[i+1].n;
const angA = Math.abs(sn) <= 1
  ? Math.asin(sn)   // 正常折射
  : curAng;          // 超過臨界角→維持原角（全反射邊界）
ifData.push({ x: ex, y: ey, angB: curAng, angA });
curAng = angA;
curN = layers[i+1].n;
介質折射率
介質折射率 n光速（相對）
空氣1.00約 3.0 × 10⁸ m/s
水1.33約 2.3 × 10⁸ m/s
食用油1.47約 2.0 × 10⁸ m/s
多層介質遞迴處理：程式採用迭代方式，依序計算每個界面的折射，curAng（當前角度）與 curN（當前折射率）在每個界面更新，支援任意層數介質組合。

Canvas 動態縮放
function lbg(cv, designW, designH) {
  const W = cv.clientWidth, H = cv.clientHeight;
  cv.width = W; cv.height = H;
  const sx = W / designW, sy = H / designH;
  const s = Math.min(sx, sy);
  ctx.setTransform(s, 0, 0, s, (W - designW*s)/2, (H - designH*s)/2);
  return { ctx, W, H };
}

所有 Canvas 場景使用 lbg() 輔助函式，以「設計空間」座標繪圖，自動等比縮放至任何螢幕尺寸，保持圖形比例與清晰度。
